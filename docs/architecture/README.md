# Architecture overview

Confluence answers natural-language questions about public companies, grounded in real SEC filings (via RAG), live market data, and the web — every claim traceable to a typed citation.

This is Phase 1: complete, running, gated. These docs describe **what exists**, not a build plan. For the deep rationale behind specific decisions (why pgvector over Chroma, why the guard truncates instead of drops, why one provider instead of several), see `CLAUDE.md` at the repo root — these docs stay short and point there for the "why."

## Quick orientation

- **Storage**: Postgres + pgvector, one table (`chunks`) doing both dense vector search and BM25 full-text, fused with Reciprocal Rank Fusion in one SQL query.
- **Corpus**: 4 tickers (AAPL, META, MSFT, TSLA), 13 filings — exactly one 10-K per ticker, the rest 10-Qs. No year-over-year *filing* comparison is answerable for any covered company; anything else is a corpus gap.
- **Agent**: two LangGraph nodes (`agent ⇄ tools`), five tools, one model (`claude-haiku-4-5-20251001`, pinned). No router node — tool docstrings *are* the routing logic.
- **Citations**: assembled in code from what each tool already knows, never generated by the model. Three types — `filing`, `news`, `web` — so a reader can see what backs a claim.
- **API**: `POST /query`, `GET /health`, `GET /threads/{id}`. Multi-turn via a Postgres checkpointer; non-streaming.

## Running it

```bash
docker compose up -d --wait                       # Postgres
.venv/bin/python -m uvicorn app.api:app --reload   # the service
```

```bash
curl -s -X POST localhost:8000/query -H 'content-type: application/json' \
  -d '{"question":"What are Apple'"'"'s key risk factors?"}' | python3 -m json.tool
```

## Testing it

```bash
.venv/bin/python -m pytest -q               # offline, no DB/keys/model needed
.venv/bin/python scripts/check_agent.py     # the agent, live — costs money
.venv/bin/python scripts/check_api.py       # the API, live — costs money, load-tests concurrency
```

Every module has a `scripts/check_*.py` gate — see each doc's "Verifying it" section for the specific one.
